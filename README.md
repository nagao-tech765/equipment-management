# 備品管理アプリ

Spring Boot と Thymeleaf を使用して作成した備品管理Webアプリケーションです。

備品の登録・検索・数量変更・ジャンル管理・保管場所の設定など、備品の在庫を管理するための機能を実装しています。

Spring Boot
Spring MVC
Thymeleaf
Spring Data JPA
HTML / CSS
JavaScript
データベース

備品の登録・削除
備品名による検索
ジャンルによる絞り込み
備品の数量変更
ジャンルの設定

## 自動減少機能

備品ごとに、一定期間が経過したら自動的に在庫数を減少させる機能を実装しています。

例えば、

7日ごとに2個減少

のように設定できます。

減少単位は「日」と「ヶ月」から選択できます。

### 自動減少の仕組み

備品ごとに以下の情報をデータベースに保存しています。

減少間隔
減少単位
減少数
最後に減少した日付

トップページへアクセスした際に、最後に減少した日付から現在までの経過期間を計算します。

設定した期間が複数回経過していた場合は、経過した回数を計算し、その回数分まとめて在庫数を減少させます。

例えば、

7日ごとに2個減少
最後の減少から21日経過

していた場合、

21 ÷ 7 = 3回
3 × 2個 = 6個減少


というように計算します。

また、在庫数が0未満にならないように制御しています。

## 工夫した点

自動減少処理では、単純にアクセスするたびに一定数を減らすのではなく、最後に減少した日付を基準に経過期間を計算する仕組みにしています。

これにより、ユーザーが毎日アクセスしなくても、次回アクセスした際に経過した期間分をまとめて反映できます。

また、複数期間が経過していた場合にも対応し、経過回数に応じて減少数を計算するようにしています。

## 在庫警告機能

備品ごとに在庫警告数を設定できます。

設定した数量以下になると、備品一覧に警告を表示します。

⚠ 在庫が少ないです

## 備品検索

備品名を入力して検索できます。

備品名の部分一致による検索に対応しています。

また、ジャンルを指定して備品を絞り込むこともできます。

## 備品設定

登録済みの備品ごとに設定ボタンから以下の情報を変更できます。

ジャンル
保管場所
自動減少
在庫警告数

自動減少設定の解除や、備品自体の削除も設定画面から行えます。
